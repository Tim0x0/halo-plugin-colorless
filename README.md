# halo-plugin-colorless

Halo 插件「无色界」：在公祭日、纪念日等指定日期让站点整天显示为灰白效果，结束后自动恢复；也可以手动一键变灰。

## 安装

从 [Releases](https://github.com/Tim0x0/halo-plugin-colorless/releases) 下载 jar，在 Halo 后台「插件」页面上传安装。要求 Halo ≥ 2.26.0。

## 使用

安装并启用插件后，在插件设置页配置以下选项：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 作用范围 | 全站或仅首页 | 仅首页 |
| 手动变灰 | 开启后立即变灰，直到手动关闭；关闭后仍按清明与纪念日判断 | 关闭 |
| 清明 | 按节气公式计算，每年 4 月 4 日或 5 日当天变灰 | 开启 |
| 纪念日 | 纪念日列表，当天命中任意一条即变灰，见下文 | 预填 5 条 |
| 时区 | 决定「今天」是哪一天；留空使用 Halo 服务端时区 | 北京时间 |

临时不想变灰时，停用插件即可。

### 纪念日

变灰与恢复都以**日期**为单位：从当天 0 点变灰，到当天 24 点结束（以设置的时区为准），不涉及具体时刻。每天独立判断：清明开关命中，或列表任意一条命中，即变灰。

每条纪念日先选类型，再选对应的日期：

| 类型 | 选择 | 说明 |
| --- | --- | --- |
| 每年重复 | 月份、日期 | 每年的这一天。日期选项随月份变化（4 月没有 31 日，2 月到 28 日）。2 月 29 日不是每年都有，请用指定日期 |
| 指定日期 | 日期选择器 | 仅当天生效，适合临时哀悼日 |

连续多天请添加多条（例如 5 月 19、20、21 日各一条）。

清明按节气浮动，因此单独用开关控制，不放进纪念日列表。默认预填以下每年重复的纪念日，可自行增删：

| 日期 | 名称 |
| --- | --- |
| 5 月 12 日 | 汶川地震纪念日 |
| 7 月 7 日 | 七七事变纪念日 |
| 9 月 18 日 | 九一八事变纪念日 |
| 9 月 30 日 | 烈士纪念日 |
| 12 月 13 日 | 南京大屠杀死难者国家公祭日 |

## 开发

插件开发的详细文档请查阅：<https://docs.halo.run/developer-guide/plugin/introduction>

所需环境：

1. JDK 21
2. Docker（可选，仅 `haloServer` 需要）

```bash
./gradlew build      # 构建，产物 build/libs/halo-plugin-colorless-<version>.jar
./gradlew test       # 运行单元测试
./gradlew haloServer # 需要 Docker，启动 Halo 并加载本插件
```
